Verdict

Rewrite the predicate. Do not add an index. An index on CreationDate does not help while the column is wrapped in YEAR() — the engine still evaluates the function for every row before it can compare anything.

The rewrite is free: no storage, no write penalty, no migration. Its only trap is the boundary, which must be half-open — < '2013-01-01', not <= '2012-12-31', which silently drops rows timestamped during the last day.
